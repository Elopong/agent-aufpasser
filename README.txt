AGENT AUFPASSER – WEBSITE

Diese Dateien bilden eine STATISCHE INFORMATIONSWEBSEITE ab und sind KEINE laufende Agenten-Anwendung.

VOR DER VERÖFFENTLICHUNG:
1. In datenschutz.html [Name/Organisation eintragen] und [Kontakt-E-Mail eintragen] ersetzen.
2. Text über Speichervorgänge, Token-Widerruf und Datenlöschung anhand der tatsächlichen Programmversion prüfen; ggf. ergänzen.
3. YouTube-Branding prüfen: YouTube empfiehlt offizielle Markenassets, die an YouTube-Inhalte verlinkt sind. Der auf der Seite verlinkte Bildpfad ist extern und kann sich ändern. Vor Audit echten Screenshot im Browser überprüfen; ggf. offizielles YouTube-Asset aus den Markenrichtlinien verwenden.
4. Website veröffentlichen, z.B. auf GitHub Pages: Neues PUBLIC Repository > index.html, datenschutz.html, style.css hochladen > Settings > Pages > Deploy from branch > main / root > Save.
5. Erst nach echter Veröffentlichung Screenshots von Startseite mit YouTube-Bereich & Datenschutzlink und der veröffentlichten Datenschutzseite erstellen.
6. Eine öffentliche Informationsseite ist nicht automatisch ein vollwertiger API-Audit-Zugang zu der lokal laufenden App. Google kann eine ausführbare Demoversion oder weitere Nachweise anfordern.
