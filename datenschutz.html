2. YouTube API Services

Für autorisierte Video-Uploads nutzt Agent Aufpasser die YouTube Data API v3. Wenn die Upload-Funktion verwendet wird, können Videodateien, Titel, Beschreibungen und weitere für den Upload erforderliche Informationen an Google bzw. YouTube übertragen werden. Die App ist nicht von YouTube betrieben oder gesponsert.

Es gelten auch die YouTube-Nutzungsbedingungen und die Google-Datenschutzerklärung.

3. Welche Daten verarbeitet werden

  • OAuth-Berechtigungen und Zugriffstoken für die autorisierte Verbindung.
  • Lokal erstellte Videoentwürfe, Dateien und zugehörige Metadaten.
  • Technische Upload-Antworten und Fehlerhinweise.
  • Gegebenenfalls die für den Upload notwendigen Kanalinformationen.

Die genaue Speicherung muss anhand der tatsächlich verwendeten Softwareversion überprüft werden. Die Website selbst bietet keine Anmeldung an.

4. Verarbeitung und Speicherung

Das Sprachmodell Ollama kann lokal auf dem Computer betrieben werden. Arbeitsdateien und Zugangsdaten können lokal gespeichert sein. Bei aktivierter Google-Sheets-Synchronisierung werden entsprechende Status- und Arbeitsdaten zusätzlich über Google-Dienste verarbeitet. Details sind abhängig von der konkreten Konfiguration.

5. Berechtigungen und Widerruf

Der Kontoinhaber autorisiert den Zugriff über Google OAuth 2.0. Er kann Berechtigungen jederzeit auf der Google-Seite zur Verwaltung verbundener Anwendungen widerrufen.

6. Datenlöschung

Nach Widerruf sollten lokal gespeicherte OAuth-Tokens und nicht mehr notwendige YouTube-API-Daten gemäß den geltenden API-Richtlinien entfernt werden. Anfragen zur Löschung können an die oben angegebene Kontaktadresse gerichtet werden. Vor Veröffentlichung ist sicherzustellen, dass dieser Ablauf tatsächlich eingerichtet ist und funktioniert.

Bereits hochgeladene Videos verbleiben grundsätzlich auf YouTube, bis sie dort separat gelöscht werden.
